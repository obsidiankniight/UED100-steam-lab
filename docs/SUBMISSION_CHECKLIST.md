## Suggested real-user test tasks

1. Find an RPG and add it to your wishlist; note time and any confusion.
2. Remove a game from your cart; check whether the total is understandable.
3. Collapse an unhelpful recommendation shelf; reload and check its persistence.
4. Open Friends & Chat without a mouse, then close it with Escape.
5. On mobile, locate the non-Steam game option in Library and add a name.

Record tester feedback without identifying personal information. Prioritise a change that helps novices but does not remove discovery options for returning users.

**Read `docs/QA_STATUS.md` before submission.** Automated checks do not substitute for the missing Figma, public Git, and human testing evidence.
