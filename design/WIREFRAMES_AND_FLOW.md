Three self-contained SVG wireframes are supplied:

- `mobile_home_wireframe.svg`: mobile Store hierarchy, genre shortcuts, shelf cards.
- `desktop_game_wireframe.svg`: detail art, purchase actions, media gallery.

The SVGs are editable vector wireframes, but **they are not a completed Figma project or a clickable Figma prototype**. Share/export the resulting design file as part of the assessment evidence.

## Core user journey

1. **New user:** Store home → browse genre → filter → game detail → cart → simulated checkout. Clear search/navigation and pricing reduce cognitive load.
2. **Returning user:** Store home → personalised shelf → wishlist → game detail. Collapsible/hidden sections reduce overload without removing discovery opportunities for publishers.
3. **Library user:** Library → recently played → small secondary 'Add a non-Steam game' option at the bottom of the Library. This option does not distract Store shoppers.
4. **Social user:** Friends & Chat strip → panel expands upward by hover, keyboard focus or click/tap. Fictional names and statuses are illustrative only.

## Relationship to Assessment 1

Assessment 1 identified information density, potentially confusing discovery for newcomers, returning-player value from wishlists and personalisation, and requirements for responsive and accessible front-end components. The redesign responds with a simplified visual hierarchy, clear genre navigation, local wishlist/cart and shelves, semantic HTML, visible focus states, mobile layouts, original compressed SVG assets, and safe input handling.
